CRISP-DM Phases

Project Overview

🎯

Research Question

Which fuzzy membership functions and hybrid strategies yield the most accurate fake-news detection?

🧠

Approach

Combines fuzzy logic with deep learning (BERT) to handle uncertainty inherent in political fact-checking.

📊

Success Criteria

Improved Accuracy, Macro-F1, and Micro-F1 scores with robustness against ambiguous statements.

🗂️

Dataset

LIAR2 dataset — 23,000+ professionally fact-checked political statements with 6-point truth ratings.

CRISP-DM Methodology

Six structured phases guiding the research from business understanding to deployment.

1

Business Understanding

Define research objectives, success criteria, and scope of the fake-news detection problem.

2

Data Understanding

Explore LIAR2 dataset — speaker history, class distribution, missing justifications, and noisy context.

3

Data Preparation

Text cleaning, tokenization, date standardization, fuzzy input engineering, and BERT embedding integration.

4

Modeling

Train 8 FDHN variants with different fuzzy membership functions and hybrid strategies.

5

Evaluation

Accuracy, Macro/Micro-F1, confusion matrices, ablation studies, and statistical significance tests.

6

Deployment

Package the best-performing FDHN variant as a production-ready fact-checking tool.

Fuzzy Membership Functions

〜

Gaussian

Smooth bell-shaped curves

Models uncertainty with smooth, continuous membership values. Ideal for naturally distributed linguistic variables.

μ(x) = e^(-(x-c)²/2σ²)
△

Triangular

Computationally efficient

Simple piecewise-linear membership function. Low computational cost, suitable for real-time applications.

Piecewise Linear
⌂

Trapezoidal

Stable membership regions

Flat-top function providing a stable region of full membership. Handles imprecise boundaries effectively.

Flat-top Function
∫

Sigmoid

Smooth transitions

S-shaped curve enabling smooth transitions between membership states. Naturally compatible with neural networks.

μ(x) = 1/(1+e^(-x))
∿

Bell-shaped

Flexible modeling

Generalized bell curve with three parameters for flexible shape control. More adaptable than standard Gaussian.

Generalized Bell

Evaluation & Results

Comprehensive metrics across all model variants.

🎯

Accuracy

Overall classification accuracy across all 6 truth-rating classes.

📐

Macro-F1

Unweighted mean F1 across classes — treats all classes equally regardless of size.

📏

Micro-F1

Aggregate F1 weighted by class frequency — reflects overall system performance.

🔬

Ablation Study

Isolates the contribution of each component — fuzzy layer, BERT, and hybrid strategy.

📉

Confusion Matrix

Per-class error analysis to identify systematic misclassification patterns.

📊

Statistical Tests

Significance testing to confirm that performance differences are not due to chance.
